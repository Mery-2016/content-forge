# ContentForge // Social Engine

> Современное веб-приложение для быстрой генерации структурированного контента под Telegram, YouTube и Instagram на базе **Google Gemini API** (`gemini-3.5-flash-lite`).

---

## 🌟 Возможности проекта

1. **Адаптация под 3 социальные сети**:
   - **Telegram** (фирменный голубой `#229ED9`): плотный текст без воды, короткие абзацы, тире, вовлекающий вопрос и до 3–4 хэштегов.
   - **Instagram** (розово-малиновый `#C13584` с градиентной иконкой): стоп-скролл хук, воздух, списки, призыв написать кодовое слово в Директ и до 10 целевых хэштегов.
   - **YouTube** (сигнальный красный `#E53935`): заголовок с высоким CTR, SEO-сниппет, блок таймкодов (00:00) и теги.

2. **Двуязычный интерфейс и генерация (RU / UZ)**:
   - Полная локализация интерфейса на **русский** и **узбекский (латиница)** с переключателем в шапке.
   - Отдельный селектор **«Язык текста / Matn tili»**: генерация контента на узбекском или русском языках.
   - Сохранение языка между сессиями (`localStorage`) без потери введённых данных.

3. **Стриминг в реальном времени (SSE)**:
   - Потоковая передача данных через Server-Sent Events и официальный SDK `@google/genai`.
   - Мягкая анимация появления слов (Word-by-word fade-in).

4. **4 интерактивных блока в каждом варианте**:
   - Заголовок / Хук (`Headline`)
   - Основной текст (`Body`)
   - Призыв к действию (`CTA`)
   - Хэштеги (`Tags`) с возможностью скопировать каждый тег по отдельности.

5. **Тактильный фидбек и копирование**:
   - Кнопка «Скопировать всё» и копирование отдельных зон.
   - Мягкая вспышка контура (350 мс) и морфинг кнопки в «Скопировано ✓» на 1.5 секунды.

6. **История постов**:
   - Выдвижная панель с быстрым поиском, фильтрацией по соцсетям и мгновенным восстановлением генераций.
   - Локальное сохранение до 100 записей.

7. **Автономный демо-режим**:
   - Если API-ключ не указан, включается умный эмулятор генерации на выбранном языке с сохранением всех правил и физики стриминга.

---

## 🛠 Технологический стек

- **Frontend**: React 18, TypeScript, Vite, Zustand, Lucide Icons, чистый адаптивный CSS с переменными.
- **Backend**: Node.js, Express, `@google/genai` (официальный Gemini SDK), Server-Sent Events (SSE).
- **Стилистика**: светлая палитра (молочный фон `#F7F5F2`, белые карточки `#FFFFFF`, глубокий синий акцент `#234B83`).

## 🚀 Быстрый запуск

### 1. Клонирование и установка зависимостей
```bash
git clone <url-вашего-репозитория>
cd ai-social-generator
npm install
```

### 2. Настройка окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```

В файле `.env` укажите ваш ключ Google Gemini:
```env
PORT=3001
GEMINI_API_KEY=ваш_ключ_от_Google_AI_Studio
GEMINI_MODEL=gemini-3.5-flash-lite
```
*(API-ключ также можно ввести прямо в интерфейсе через кнопку «API Ключ» в шапке)*.

### 3. Запуск проекта в режиме разработки
```bash
npm run dev
```

После запуска откройте в браузере:
- **Интерфейс**: [http://localhost:5173](http://localhost:5173)
- **API-сервер**: [http://localhost:3001](http://localhost:3001)

### 4. Сборка для продакшна
```bash
npm run build
npm start
```
